# JavaScript Objects: Cheat Sheet

## 1. Object Basics

Objects are collections of related variables (properties) and functions (methods).

```js
const circle = {
  radius: 1,
  location: { x: 1, y: 1 }, // Nested object
  draw() {
    console.log("draw")
  }, // Method
}
```

---

## 2. Dynamic Nature & Built-in Objects

Objects are not static; you can modify them at runtime. Use built-in objects for common tasks.

```js
const user = { name: "John" }
user.age = 30 // Add property
delete user.name // Delete property

// Math & Date
Math.random()
const now = new Date()
const specificDate = new Date(2026, 0, 2) // Year, Month (0-index), Day
```

---

## 3. Strings & Template Literals

JS wraps primitive strings in an object automatically to provide methods.

```js
const name = "Alice"
const message = `Hi ${name},
This is a "template" literal.` // Supports multi-line and interpolation

console.log(name.length) // 5
console.log(name.includes("A")) // true
```

---

## 4. Factory vs. Constructor Functions

Patterns used to create multiple objects without code duplication.

| Feature    | Factory Function             | Constructor Function                              |
| :--------- | :--------------------------- | :------------------------------------------------ |
| **Naming** | camelCase (`createCircle`)   | PascalCase (`Circle`)                             |
| **Return** | Explicitly returns an object | Uses `this` and `new` (returns `this` implicitly) |
| **Syntax** | `return { ... }`             | `this.radius = radius;`                           |

```js
// Factory
function createCircle(radius) {
  return { radius, draw() {} }
}

// Constructor
function Circle(radius) {
  this.radius = radius
  this.draw = function () {}
}
const myCircle = new Circle(1)
```

---

## 5. Value vs. Reference Types

Crucial for understanding how data is stored and copied.

- **Primitives:** (Number, String, etc.) Copied by **value**. Variables are independent.
- **Objects:** (Object, Array, Function) Copied by **reference**. Variables point to the same memory address.

```js
// Reference Example
let x = { value: 10 }
let y = x
x.value = 20
console.log(y.value) // 20 (Both point to the same object)
```

---

## 6. Enumerating & Cloning

Iterating through properties and creating "true" copies.

```js
const circle = { radius: 1, draw() {} }

// Enumerating
for (let key in circle) console.log(key) // keys
if ("radius" in circle) console.log("exists") // check property

// Cloning (Shallow copies)
const clone1 = Object.assign({}, circle) // Old way
const clone2 = { ...circle } // Modern Spread Operator
```

---

## 7. Advanced: Object Behavior Control

JavaScript provides methods to prevent an object from being modified.

```js
const car = { speed: 100 }

// Prevent adding/removing properties, but allows changing values
Object.seal(car)

// Prevent ANY changes (read-only)
Object.freeze(car)

// Check state
console.log(Object.isFrozen(car)) // true
```

---

## 8. Development Tips

- **Use Property Shorthand:** If the key name and variable name are the same, you don't need to repeat them.
  ```js
  const name = "Alice"
  const user = { name } // Same as { name: name }
  ```
- **Computed Property Names:** You can use a variable as a key name by using square brackets.
  ```js
  const key = "status"
  const user = { [key]: "active" } // { status: 'active' }
  ```
- **Shallow vs. Deep Copy:** Standard cloning (`...` or `Object.assign`) only creates a **shallow copy**.
  - **Shallow Copy:** Copies top-level properties. Nested objects still share the same reference.
  - **Deep Copy:** Recursively copies all levels. Use `structuredClone(obj)`.
    ```js
    const original = { a: 1, b: { c: 2 } }
    const deep = structuredClone(original)
    deep.b.c = 100 // Original remains unchanged
    ```
- **Memory Management:** JS **Garbage Collection** handles deallocation automatically.
- **Naming Clarity:** Use **Factory Functions** for simple literals; use **Constructor Functions** for standard OOP patterns.
