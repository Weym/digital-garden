# JavaScript Control Flow: Ranked by Difficulty

## 1. Conditionals: If...Else (Basic)

Branching logic based on truthy conditions.

```js
if (condition) {
  // statement
} else if (anotherCondition) {
  // statement
} else {
  // statement
}
```

---

## 2. Conditionals: Switch...Case (Basic)

Matches a value against multiple cases. Use `break` to prevent "falling through."

```js
switch (role) {
  case "guest":
    console.log("Guest")
    break
  default:
    console.log("Unknown")
}
```

---

## 3. Standard Loops: For, While, Do...While (Intermediate)

Mechanisms for repeating code.

- **For**: Best when the number of iterations is known.
- **While**: Best when waiting for a condition.
- **Do...While**: Always executes **at least once**.

```js
for (let i = 0; i < 5; i++) {
  ;/_ logic _/
}

while (i < 5) {
  i++
}

do {
  i++
} while (i < 5)
```

---

## 4. Specialized Loops: For...In & For...Of (Intermediate)

Efficient ways to iterate over objects and arrays.

| Feature           | `for...in`                           | `for...of`                     |
| :---------------- | :----------------------------------- | :----------------------------- |
| **Iterates Over** | Enumerable **property names** (keys) | **Values** of iterable objects |
| **Best For**      | Objects (keys/properties)            | Arrays, Strings, Maps (values) |
| **Returns**       | Strings (keys)                       | Values themselves              |

```js
const obj = { a: 1, b: 2 }
for (let key in obj) console.log(key, obj[key]) // 'a' 1, 'b' 2

const arr = ["red", "blue"]
for (let color of arr) console.log(color) // 'red', 'blue'
```

---

## 5. Loop Control: Break, Continue & Labels (Intermediate/Advanced)

Commands to alter loop execution mid-stream.

```js
// Break: Exits loop. Continue: Skips to next iteration.
for (let i = 0; i < 10; i++) {
  if (i === 5) break
  if (i % 2 === 0) continue
}

// Labels: Break out of an outer loop from an inner one
outer: for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    if (i === 1) break outer
  }
}
```

---

## 6. Advanced: Array Iteration Methods

Modern functional approaches that are often preferred over standard `for` loops.

```js
const numbers = [1, 2, 3];

const doubled = numbers.map(n => n \* 2); // returns NEW array
const evens = numbers.filter(n => n % 2 === 0); // returns matching items
const sum = numbers.reduce((acc, n) => acc + n, 0); // collapses to single value
```

---

## 7. Development Tips

Best practices for writing cleaner, more professional control flow.

- **The Early Return Pattern:** Avoid "Else" blocks and deep nesting. If a condition isn't met, exit the function immediately.
  ```js
  // Clean code approach
  function getPay(isEmployee, hours) {
  if (!isEmployee) return null;
  if (hours <= 0) return 0;
  return hours \* 20;
  }
  ```
- **Avoid Infinite Loops:** Always ensure your loop condition will eventually become `false` or include a `break` statement.
- **Prefer `for...of` over `for...in` for Arrays:** `for...in` is significantly slower on arrays and may return properties you don't expect.
- **Declarative > Imperative:** Use Array methods (`map`, `filter`) instead of `for` loops when possible to make code more readable and easier to test.
