# JavaScript Operators: Ranked by Difficulty

## 1. Arithmetic & Assignment (Basic)

Standard math and shorthand for updating variable values.
| Type | Operator | Example | Result |
| :--- | :--- | :--- | :--- |
| **Arithmetic** | `+`, `-`, `*`, `/` | `10 / 2` | `5` |
| **Remainder** | `%` | `10 % 3` | `1` |
| **Exponent** | `**` | `2 ** 3` | `8` |
| **Increment** | `++x` vs `x++` | `++5` → `6` | Pre vs Post |
| **Combined** | `+=`, `-=`, `*=` | `x += 5` | `x = x + 5` |

---

## 2. Equality (Basic)

The distinction between comparing just values versus comparing both value and type.
| Operator | Type | Behavior |
| :--- | :--- | :--- |
| `===` | **Strict** | Checks Value + Type (Recommended) |
| `==` | **Loose** | Checks Value only (Type coercion) |

```js
1 === "1" // false
1 == "1" // true
```

---

## 3. Variable Swap (Intermediate)

Common logic patterns for exchanging data between variables.

```js
let a = 1,
  b = 2

// Classic (Temp variable)
let temp = a
a = b
b = temp

// Modern (Destructuring assignment)
;[a, b] = [b, a]
```

---

## 4. Ternary Operator (Intermediate)

A concise, one-line alternative to `if...else` blocks.

```js
// condition ? valueIfTrue : valueIfFalse;
let status = age >= 18 ? "adult" : "minor"
```

---

## 5. Logical & Short-Circuiting (Intermediate)

Using Truthy/Falsy logic to control flow and set defaults.

```js
// Falsy: false, 0, '', null, undefined, NaN

let color = userColor || "blue" // OR: Returns first Truthy (Defaulting)
let access = isActive && hasToken // AND: True only if both are Truthy
```

---

## 6. Nullish Coalescing & Optional Chaining (Advanced)

Modern operators for safe property access and precise null handling.

```js
// Nullish Coalescing (??) - Ignores 0 and ''
let speed = 0
let val = speed ?? 10 // Result: 0 (unlike || which would return 10)

// Optional Chaining (?.) - Prevents crashes on missing objects
console.log(user.settings?.theme)
```

---

## 7. Logical Assignment (Advanced)

Combining logical checks with assignment in a single step for cleaner state updates.

```js
x ||= y // Assign y if x is Falsy
x &&= y // Assign y if x is Truthy
x ??= y // Assign y if x is Nullish (null/undefined)
```

---

## 8. Bitwise Operators (Advanced)

Low-level operations on binary bits, primarily used for flag and permission systems.

```js
const READ = 4,
  WRITE = 2
let myPerms = READ | WRITE // Add permission (OR)
let hasRead = (myPerms & READ) > 0 // Check permission (AND)
```

# JavaScript Operators Practice Exercises

These exercises cover the most critical concepts using the Pareto principle—maximum learning from minimal problems.

### Exercise 1: Operator Combinations

```js

let discount = 15

// Check if final price is less than 90 using strict equality
// Store result in a variable called 'isCheap'
```

```js

let isSubscribed = null

// - username should default to 'Guest'
// - age should default to 18
// - isSubscribed should default to false

// Then use && to create a welcome message only if username is NOT 'Guest'
```


### Exercise 4: Bitwise Permissions

```js

const WRITE = 2

// 2. Check if the file has WRITE permission (should be false)

```

### Exercise 5: The Swap Challenge

```js

let b = "second"

// After swapping: a='third', b='first', c='second'
// Use minimum temporary variables
```

