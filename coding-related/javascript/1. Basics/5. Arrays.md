# JavaScript Arrays: Cheat Sheet

## 1. Adding & Removing Elements

Methods that modify the original array (mutability).

| Action     | Start of Array | End of Array | Specific Position       |
| :--------- | :------------- | :----------- | :---------------------- |
| **Add**    | `unshift(val)` | `push(val)`  | `splice(index, 0, val)` |
| **Remove** | `shift()`      | `pop()`      | `splice(index, count)`  |

```js
const numbers = [3, 4]
numbers.push(5, 6) // [3, 4, 5, 6]
numbers.unshift(1, 2) // [1, 2, 3, 4, 5, 6]
numbers.splice(2, 0, "a") // [1, 2, 'a', 3, 4, 5, 6]
```

---

## 2. Finding Elements

Searching for values varies depending on whether they are primitives or objects.

- **Primitives:** Use `indexOf(val)` or `includes(val)`.
- **Reference Types:** Use `find(predicate)` or `findIndex(predicate)`.

```js
const numbers = [1, 2, 3, 1]
numbers.indexOf(1) // 0
numbers.lastIndexOf(1) // 3
numbers.includes(1) // true

const courses = [{ id: 1, name: "JS" }]
courses.find(c => c.name === "JS") // { id: 1, name: 'JS' }
```

---

## 3. Combining & Slicing

Creating new arrays from existing ones.

```js
const first = [1, 2]
const second = [3, 4]

// Combined (New Array)
const combined = [...first, "mid", ...second] // Spread operator (Modern)
const concat = first.concat(second) // Concat method

// Slicing
const slice = combined.slice(1, 3) // Extracts index 1 to 2
```

---

## 4. Iterating & Joining

Moving through elements or converting the array into a string.

```js
const arr = [1, 2, 3]

// Iteration
arr.forEach((num, index) => console.log(index, num))

// Joining & Splitting
const csv = arr.join(",") // "1,2,3"
const parts = "a b c".split(" ") // ["a", "b", "c"]
```

---

## 5. Sorting & Testing

Reordering elements or checking conditions across the whole array.

```js
const items = [2, 3, 1]
items.sort() // [1, 2, 3]
items.reverse() // [3, 2, 1]

// Testing (Returns Boolean)
const allPositive = items.every(v => v > 0) // true if ALL match
const somePositive = items.some(v => v > 0) // true if AT LEAST ONE matches
```

---

## 6. Functional Methods (Filter, Map, Reduce)

High-order functions that are the standard for modern JS data processing.

```js
const numbers = [1, -1, 2, 3]

// Filter: Keeps elements that pass a test
const filtered = numbers.filter(n => n >= 0) // [1, 2, 3]

// Map: Transforms each element
const mapped = filtered.map(n => ({ value: n })) // Objects: [{value: 1}, ...]

// Reduce: Collapses array into a single value (sum, avg, etc.)
const sum = numbers.reduce((acc, curr) => acc + curr, 0) // 5
```

---

## 7. Advanced: Immutability & Modern Methods

Methods introduced to handle arrays without changing the original data (Non-mutating).

```js
const arr = [3, 1, 2]

// toSorted(), toReversed(), toSpliced()
// These return a NEW array instead of modifying the original
const sorted = arr.toSorted()

// .at() - Access elements using negative indices
console.log(arr.at(-1)) // returns 2 (last element)

// .flat() - Flatten nested arrays
const nested = [1, [2, [3]]]
console.log(nested.flat(2)) // [1, 2, 3]
```

---

## 8. Development Tips

- **Memory Management:** `numbers.length = 0` is the fastest way to clear an array while keeping all existing references alive.
- **Avoid `for...in` for Arrays:** It iterates over properties (including custom ones), not just numeric indices. Use `for...of`.
- **Deep Flattening:** Use `.flatMap()` if you need to map an item and flatten the result in one single, high-performance step.
- **Performance of Unshift/Shift:** Adding or removing from the _beginning_ of an array requires re-indexing every other element. For very large arrays, this is much slower than `push/pop`.
- **Cloning for Sort:** Since `sort()` is destructive, always clone first if you need to keep the original order: `[...data].sort()`.
- **Arrow Function Objects:** Always wrap object literals in parentheses when mapping: `map(x => ({ id: x }))`.
- **Unique Values:** To quickly remove duplicates from an array, use a **Set**:
  ```js
  const unique = [...new Set([1, 2, 2, 3])] // [1, 2, 3]
  ```
